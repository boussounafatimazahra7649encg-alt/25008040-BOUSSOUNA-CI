## 1. Présentation du sujet

Ce projet porte sur l'analyse des exportations agricoles du Maroc dans le cadre du module Science des données et Machine Learning appliqués au commerce international (S7 – ENCG Settat).

**Code du sujet :** CI12  
**Intitulé :** Exportations agricoles marocaines

L'objectif est d'exploiter les données du commerce international afin d'étudier l'évolution des exportations agricoles marocaines et d'appliquer une méthode de Machine Learning pour analyser et prévoir leur comportement.

## 2. Source des données

Les données utilisées proviennent de la base de données officielle UN Comtrade, qui fournit des statistiques sur le commerce international des marchandises.

- Organisme : United Nations Statistics Division (UNSD).
- Source : UN Comtrade.
- Site officiel : https://comtradeplus.un.org/
- Pays déclarant : Maroc.
- Flux commercial : Exportations.
- Période étudiée : 2015–2025.
- Date d'extraction : 19/11/2026.
- Licence et conditions de réutilisation : à vérifier auprès de la source officielle.

## 4. Méthodologie

Le projet suit une démarche de science des données comprenant :

1. Compréhension et exploration des données.
2. Nettoyage et préparation du jeu de données.
3. Visualisation des principales tendances des exportations.
4. Application d'un algorithme de Machine Learning.
5. Évaluation et interprétation des résultats.
